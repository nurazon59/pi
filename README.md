# pi

Personal [Pi](https://pi.dev/) extensions.

## Extensions

- `statusline`: custom status line
- `ask-user`: interactive question UI
- `plan-mode`: planning and review UI

## Installation

```sh
pi install git:github.com/nurazon59/pi
```

Source files were initially copied from [nurazon59/dotfiles](https://github.com/nurazon59/dotfiles/tree/main/config/.config/pi/extensions).

Runtime settings and keybindings remain managed by dotfiles.
